> **Interactive Sales Dashboard developed using Microsoft Excel**

![Sales Dashboard](06-Images/Dashboard_Preview.png)

*The dashboard provides dynamic business insights using slicers, Pivot Tables, Power Pivot, KPIs, and interactive charts.*

---

## 📌 Project Overview

This project analyzes the Sample Superstore dataset to identify sales trends, profitability, customer behaviour, product performance, and regional business performance.

The project combines **Advanced Excel** for dashboard development and **SQL (MySQL)** for business query analysis to provide meaningful business insights for decision making.

---

## 🎯 Business Problem

Businesses often generate large amounts of sales data but struggle to answer important questions such as:

- Which products generate the highest profit?
- Which regions perform best?
- Which customers contribute the most revenue?
- How do discounts affect profitability?
- Which categories require business attention?

This project answers these questions through interactive dashboards and SQL analysis.

## 💡 Key Business Insights

Major findings from the project include:

- 📱 Phones generated the highest sales among all sub-categories.
- 📎 Fasteners generated the lowest sales.
- 👤 Consumer Segment contributed the highest revenue.
- 🗺 California recorded the highest sales.
- 💹 Technology generated the highest overall profit.
- 🎯 Zero Discount transactions produced the highest profit.
- 📉 High discounts significantly reduced profitability.
- 📦 Return Rate remained around **5.91%**.
- 📈 November recorded the highest monthly sales.
- 👥 Customer analysis identified top revenue-generating customers.
