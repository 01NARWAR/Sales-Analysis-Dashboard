# 📌 Project Overview

This SQL project analyzes retail sales data using MySQL to answer business questions and generate valuable insights.

The project covers the complete SQL workflow, including database creation, data import, querying, aggregation, joins, views, and business reporting.

The objective is to transform raw sales data into meaningful information that supports data-driven business decisions.

---

The project uses a retail sales database designed to support business analysis.

# 📋 Tables

The Orders table contains transaction-level sales information including:

- Product Name
- Category
- Sub-Category
- Region
- Sales
- Quantity
- Discount
- Profit

# 💡 Business Insights

The SQL analysis revealed several valuable business insights:

- 📱 Phones generated the highest sales.
- 📎 Fasteners recorded the lowest sales.
- 👥 Consumer Segment generated the highest revenue.
- 🌎 California achieved the highest sales.
- 💰 Technology was the most profitable category.
- 📉 Higher discounts reduced overall profitability.
- 📅 November recorded the highest monthly sales.
- ⭐ Top customers contributed significantly to total revenue.

These findings support better business planning and strategic decision-making.
