This project demonstrates end-to-end Sales Data Analysis using MySQL.

The project covers business analysis through SQL queries including:

- KPI Analysis
- Sales Analysis
- Profit Analysis
- Customer Analysis
- Product Analysis
- Regional Analysis
- Returns Analysis
- Shipping Analysis
- Time Series Analysis
- Advanced Business Insights

## Project Objective

The objective of this project is to analyze Superstore sales data using SQL and answer real-world business questions.

The project focuses on:

- Measuring business KPIs
- Identifying sales trends
- Understanding customer behavior
- Analyzing product performance
- Finding profitable regions
- Measuring return rates
- Evaluating shipping performance
- Generating executive business insights

---

## Business Problems

Business managers need answers to questions like:

- Which product categories generate the highest sales?
- Which products generate the highest profit?
- Which customers contribute the most revenue?
- Which states generate maximum profit?
- Which regions have the highest return rate?
- Which shipping mode performs the best?
- How are sales changing over time?
- What are the overall business KPIs?

This project answers all these business questions using SQL.

## Key Business Insights

- Technology category generated the highest profit.
- California recorded the highest sales.
- Standard Class handled the largest number of orders.
- A small number of customers contributed a major share of revenue.
- Higher discounts often reduced profitability.
- Return rate remained around 6%.
- Sales showed strong growth during year-end months.
